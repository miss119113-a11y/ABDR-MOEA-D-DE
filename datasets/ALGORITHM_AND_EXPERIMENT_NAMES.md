# Publication naming conventions

**Official manuscript algorithm name:** ABDR-MOEA/D-DE.

| Publication term | Meaning | Earlier internal identifiers |
|---|---|---|
| ABDR-MOEA/D-DE | Proposed method | BIDR-MOEA/D-DE; BI-MOEA/D-DE; ULTRA (PX4 results) |
| BI | Block inheritance and associated pressure selection | APB in archived ablation labels |
| DQR | Direction-quota replacement with its configured archive-guidance operations | DQR |
| SHDE | Success-history adaptation and associated memory controls | SHDE |
| E01 | Main algorithm comparison | MAIN |
| E02 | Ablation study | ABLATION |
| E03 | Serial runtime benchmark | separate runtime batch |
| E04 | Crater Lake external DEM evaluation | CRATER |
| E05 | Mount St. Helens external DEM evaluation | MOUNT |
| E06 | PX4-Gazebo SITL evaluation | proposed/ToP/historical mission archives |

Older internal identifiers remain in source-metadata columns for provenance; renaming does not alter the run's source implementation, numerical measurements, success/failure status, or the original source archives.

**Canonical reviewer-facing directory:** [paper_results](paper_results/README.md).
