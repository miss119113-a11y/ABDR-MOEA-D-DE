# ABDR-MOEA/D-DE experimental dataset

The **IEEE Access experimental results** are organized and named consistently in [paper_results](paper_results/README.md).

The repository contains six experiment groups (E01–E06): main comparison, ablation, serial runtime, Crater Lake, Mount St. Helens, and PX4-Gazebo SITL. Numerical results and original pass/fail measurements are preserved without modification.

- [Experiment files, sizes and descriptions](paper_results/README.md)
- [Algorithm and experiment naming conventions](ALGORITHM_AND_EXPERIMENT_NAMES.md)
- [Source records, provenance, checksums and scope](curated/README.md)
- [Archive receipt and checksum tracking](UPLOAD_STATUS_20261024.csv)

Bulk binary archives are intentionally not committed to GitHub. This repository's visibility is controlled by the owner. Check visibility before giving its link to reviewers.
